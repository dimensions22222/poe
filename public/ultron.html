        Service details
        
                
        Settings & analysis limits
        
                
        
                  Configuration and privacy details for the local analysis
                  engine.
                
        
              
        
            
        
            
        
              
        
                Analysis memoryReports and learned pattern counts persist in the local
                  SQLite database. Source HTML remains in memory until the
                  server restarts.
              
        
              
        
                Fetch boundariesHTTP(S) only · public IPs only · same-host redirects ·
                  standard ports · robots.txt respected · maximum five
                  pages.
              
        
              
        
                Analysis methodDeterministic HTML rules and retrieval-based recommendations.
                  Optional AI-enhanced insights send only extracted report
                  data—not source HTML—to OpenAI when OPENAI_API_KEY is
                  configured. No website scripts are executed.
              
        
            
        
          
        

          
        
            ULTRON analyzes retrieved HTML, not fully rendered browser sessions.
            It does not bypass access controls, fetch external assets, or scan
            for vulnerabilities.
